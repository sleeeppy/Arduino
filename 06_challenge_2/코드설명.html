06C17 도전과제 2 — PWM 함수 구현

코드 설명 (1페이지) · 주기 및 duty 설정 방법

1. 회로

5V — 220Ω — LED — GPIO7. GPIO7이 LOW일 때 LED가 켜진다 (sink).

2. 주기(period)와 duty 설정

  • set_period(int period): PWM 한 주기를 마이크로초(us)로 지정. 범위 100~10000.
  • set_duty(int duty): 한 주기에서 LED가 켜진 비율. 0~100%, 101단계. 0=꺼짐, 100=최대 밝기.

세 주기는 배열로 미리 두고, PERIOD_SELECT만 바꿔 고른다.

const int PERIODS_US[] = {10000, 1000, 100};  // 10ms, 1ms, 0.1ms
#define PERIOD_SELECT 1  // 1=10ms, 2=1ms, 3=0.1ms

setup()에서 set_period(PERIODS_US[PERIOD_SELECT - 1])를 호출한다. 시작 시 LED가 1/2/3번 깜빡여 선택한 주기를 확인한다.

3. PWM 구현

analogWrite() 없이 digitalWrite()와 delayMicroseconds()로 한 주기를 만든다.

  • 켜짐 시간 = period × duty / 100
  • 꺼짐 시간 = period − 켜짐 시간

4. 삼각파 밝기

duty를 0→100→0으로 바꾼다. 각 단계를 약 10ms 유지하므로 슬라이드 그래프처럼 1초 동안 최소→최대, 다음 1초 동안 최대→최소이다. 페이드 시간은 세 주기 모두 같고, period에 따라 깜빡임만 달라진다.

영상 촬영: PERIOD_SELECT를 1, 2, 3으로 바꿔 각각 업로드한 뒤 녹화한다.
