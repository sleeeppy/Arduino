1. 과제와 재사용

초음파 센서로 차량 접근을 감지하고, 서보암에 우드스틱을 붙여 차단기 바(bar)를 표현한다. 차가 감지되면 바를 부드럽게 올리고, 지나가면 부드럽게 내린다.

실습 3(10_example_3)은 경과 시간을 map(progress, 0, MOVING_TIME, 시작각, 끝각)으로 각도에 그대로 대응시킨다. 속도가 일정해서 출발·도착 순간에 가속도가 끊기고 바가 덜컥인다. 이 뼈대(경과 시간 → 진행률 t → 각도)는 그대로 두고, 직선 대신 이징 함수 ease(t)를 넣었다.

거리 측정은 9주차 코드를 재사용했다. 25ms마다 초음파를 읽고, timeout·범위 밖은 직전 유효값으로 유지한 뒤 EMA로 흔들림을 줄인다. 서보 보간과 측정을 같이 돌리려고 delay()로 기다리지 않고 millis()로 주기를 맞춘다.

2. 함수 선정

(1)은 슬라이드에 지정된 sigmoid(로지스틱)다. 원래 식은 아래와 같다.

σ(x) = 1 / (1 + e−x)     (x ∈ (−∞, ∞) → (0, 1))

시간 t는 0~1이므로 x = k(2t−1)로 접어 σ(−k)~σ(k) 구간만 쓴다. 그래도 양 끝이 정확히 0, 1이 아니므로 σ(−k), σ(k)로 정규화했다.

ease_sigmoid(t) = (σ(k(2t−1)) − σ(−k)) / (σ(k) − σ(−k)),   k = 8

k가 클수록 양 끝은 더 평평하고 중간만 가파르다. k=8이면 시작·끝에서 바가 거의 멈춘 뒤 가운데에서 빠르게 움직인다.

(2)는 서보·애니메이션에서 자주 나오는 함수를 검색해 cosine ease-in-out을 골랐다. smoothstep(3t²−2t³)도 후보이지만, cosine이 수식이 짧고 sigmoid와 중간 속도 특성이 달라 비교하기 좋다.

ease_cosine(t) = 0.5 · (1 − cos(πt))

FUNC_SELECT 1=sigmoid, 2=cosine. 업로드 직후 LED가 1번 또는 2번 깜빡여 어떤 함수가 올라갔는지 표시한다.

같은 장난감 차 접근을 FUNC_SELECT만 바꿔 두 번 찍으면, sigmoid는 출발이 늦고 중간에 빨라 보이며 cosine은 속도 변화가 고르다.

4. 코드 구현 설명

4.1 핀과 상수

서보 D10, TRIG D12, ECHO D13, LED D9(active-LOW). 서보 전원은 전원모듈을 쓰고 GND는 아두이노와 공통으로 묶는다.

  • 거리: 유효 구간 50~400mm. 차량 판정은 200mm 이하, 통과는 280mm 이상.
  • 각도: BAR_DOWN=0°, BAR_UP=90°. 우드스틱을 붙인 방향이 반대면 이 두 값만 바꾸면 된다.
  • MOVING_TIME=1500ms. 교재 MG90S는 60°에 약 0.1s이므로 90°는 하드웨어상 더 짧아도 되지만, 부드럽게 보이게 1.5초로 잡았다.

4.2 setup()

핀 방향을 정한 뒤 서보를 내린 상태(BAR_DOWN)로 attach하고 0.5초 기다린다. 시리얼 57600 개통 후 blink_n(FUNC_SELECT)로 함수 종류를 표시한다. 마지막에 last_sampling_time = millis()를 넣어 첫 초음파 샘플이 바로 나가지 않게 맞춘다.

4.3 초음파 측정과 범위 필터

USS_measure는 TRIG에 10µs 펄스를 넣고 pulseIn(ECHO, HIGH, TIMEOUT)으로 왕복 시간을 읽는다. SCALE = 0.001 · 0.5 · 346을 곱하면 mm가 된다. echo가 오지 않으면 timeout(0)이다. TIMEOUT = (INTERVAL/2)·1000이라서 25ms 주기를 넘기지 않는다.

0이거나 50mm 미만, 400mm 초과면 dist_filtered = dist_prev로 직전 유효값을 유지한다. 유효하면 그 값을 쓰고 dist_prev를 갱신한다. 스파이크 한두 번에 차단기가 반응하지 않게 하기 위함이다.

4.4 EMA

dist_ema = 0.5 · dist_filtered + 0.5 · dist_ema

첫 샘플을 0으로 두면 시작 직후 EMA가 작아져 바가 잘못 올라갈 수 있다. ema_ready가 0일 때는 필터된 값을 그대로 넣고, 그다음부터 위 식을 쓴다.

4.5 차량 판정 (히스테리시스)

경계 한 값만 쓰면 EMA가 그 근처에서 흔들릴 때 car_present가 0/1을 반복하고 바가 깜빡인다. 그래서 두 문턱을 썼다.

if (dist_ema <= 200) car_present = 1;      // 접근
else if (dist_ema >= 280) car_present = 0; // 통과
// 200~280mm 는 이전 상태를 유지

LED는 차량이면 LOW(켜짐), 아니면 HIGH(꺼짐)이다.

4.6 서보를 부드럽게 움직이기

start_move(from, to)가 시작각·목표각·시작 시각을 저장하고 moving=1로 둔다. loop() 앞부분에서 매 주기 아래를 계산한다.

t = (millis() − moveStartTime) / MOVING_TIME   // 0~1, 시간 비율
s = ease(t)                                    // FUNC_SELECT에 따라 sigmoid 또는 cosine
angle = startAngle + (stopAngle − startAngle) · s

실습 3의 map()은 t를 각도에 직선으로 대응시킨다. 여기서는 s가 곡선이라 같은 1.5초여도 시작·끝 속도가 다르다. t≥1이면 목표각을 한 번 더 쓰고, bar_up을 목표에 맞게 갱신한 뒤 moving=0으로 끝낸다.

동작 중에는 새 명령을 받지 않는다. 올리는 도중에 차가 사라져도 끝까지 올린 다음, 다음 주기에서 내린다. 중간에 목표를 바꾸면 이징이 끊겨 바가 튀기 때문이다.

if (!moving) {
  if (car_present && !bar_up) start_move(BAR_DOWN, BAR_UP); // 접근 → 올림
  if (!car_present &&  bar_up) start_move(BAR_UP, BAR_DOWN); // 통과 → 내림
}

4.7 loop() 전체 흐름

한 바퀴는 두 부분이다. 먼저 moving이면 서보 각도를 갱신한다. 그다음 INTERVAL(25ms)이 지났을 때만 초음파를 읽고 필터·판정·출발 조건을 처리한다. 서보 갱신은 매 loop, 측정은 25ms마다이므로 보간이 끊기지 않는다.

시리얼에는 Min, ema, car, bar, Max를 찍어 거리와 감지 여부, 바 상태를 확인한다. 시리얼 플로터를 열면 EMA와 car(0/1)가 같이 보인다.
