# 10C16 도전과제 1 — 주차장 차단기

실습 3(`10_example_3`)의 시간 보간과 9주차 초음파(범위 필터 + EMA)를 합쳤다. 직선 `map()` 대신 이징 함수로 각도를 만들어 차단기 바를 부드럽게 올리고 내린다.

## 1. 과제와 재사용

초음파로 차량 접근을 감지하고, 서보암에 붙인 바로 차단기를 표현한다. 차가 감지되면 바를 부드럽게 올리고, 지나가면 부드럽게 내린다.

실습 3은 `map(progress, 0, MOVING_TIME, 시작각, 끝각)`으로 각도를 직선 보간한다. 이 뼈대(경과 시간 → 진행률 t → 각도)는 그대로 두고, 직선 대신 `ease(t)`를 넣었다. 거리 측정은 9주차처럼 25ms마다 초음파를 읽고, timeout/범위 밖은 직전값, 그다음 EMA를 쓴다.

## 2. 함수 선정

차단기는 시작·끝에서 바가 덜컥이면 안 된다. 직선 `map()`은 속도가 일정해서 출발·도착 순간에 가속도가 끊긴다.

(1)은 슬라이드의 **sigmoid**(로지스틱)다. 원래 σ(x)=1/(1+e^(−x))는 (−∞,∞)→(0,1)이므로, 시간 t∈[0,1]에 맞춰 x=k(2t−1)로 접고 σ(−k), σ(k)로 정규화해 양 끝을 정확히 0과 1에 맞췄다. k=8이면 끝은 거의 멈추고 중간만 빠르다.

(2)는 서보·애니메이션에서 흔히 쓰는 **cosine ease-in-out** `0.5·(1−cos(πt))`를 골랐다. 수식이 짧고, sigmoid보다 중간 속도가 고라서 비교하기 좋다. smoothstep도 후보였으나 cosine이 더 직관적이다.

`FUNC_SELECT` 1=sigmoid, 2=cosine. 업로드 후 LED가 그만큼 깜빡인다.

## 3. sigmoid와 cosine 비교

같은 t에서 진행률 s=ease(t)를 비교하면 차이가 분명하다.

| t | sigmoid (k=8) | cosine |
|---|---|---|
| 0.00 | 0.00 | 0.00 |
| 0.25 | ≈0.018 | ≈0.146 |
| 0.50 | 0.50 | 0.50 |
| 0.75 | ≈0.982 | ≈0.854 |
| 1.00 | 1.00 | 1.00 |

- **양 끝:** sigmoid는 t=0.25에도 거의 안 움직이고, t=0.75면 이미 거의 도착한다. cosine은 가속·감속이 더 고르다.
- **중간:** sigmoid가 더 급하다. 차단기가 잠깐 머문 뒤 확 열리는 느낌.
- **연산:** sigmoid는 `exp`, cosine은 `cos` 하나.

같은 차 접근을 두 함수로 찍어 바의 가속 차이를 보면 된다.

## 4. 코드 구현

### 핀·상수

서보 10, TRIG 12, ECHO 13, LED 9(active-LOW). 서보 전원은 전원모듈, GND는 아두이노와 공통.

- 거리: `_DIST_MIN` 50mm, `_DIST_MAX` 400mm, `DIST_CAR` 200mm, `DIST_CLEAR` 280mm
- 각도: `BAR_DOWN` 0°, `BAR_UP` 90°. 우드스틱 방향이 반대면 이 두 값만 바꾼다.
- 동작 시간: `MOVING_TIME` 1500ms. MG90S는 60°에 약 0.1s이므로 90°는 하드웨어상 더 짧아도 되지만, 부드럽게 보이게 1.5s로 잡았다.

### setup

핀 방향 설정 후 서보를 내린 상태로 `attach`한다. 시리얼 57600, `blink_n(FUNC_SELECT)`로 어떤 함수인지 표시하고, `last_sampling_time = millis()`로 첫 샘플 타이밍을 맞춘다.

### 초음파 → 차량 판정

`USS_measure`는 TRIG 10µs 펄스 후 `pulseIn`으로 echo를 읽고 `SCALE`을 곱해 mm로 바꾼다. timeout이면 0이 나온다.

범위 필터: 0이거나 50mm 미만, 400mm 초과면 `dist_prev`를 유지한다. 유효하면 `dist_prev`를 갱신한다.

EMA: 첫 유효값은 그대로 넣고, 이후 `0.5·filtered + 0.5·이전 EMA`. 첫 샘플을 0으로 두면 초기에 바가 잘못 움직이므로 `ema_ready`로 막았다.

히스테리시스: EMA ≤ 200mm면 차량, ≥ 280mm면 통과. 200~280mm는 이전 `car_present`를 유지한다. 경계 한 값만 쓰면 노이즈에 바가 깜빡인다.

### 서보 보간

`start_move(from, to)`가 `startAngle`, `stopAngle`, `moveStartTime`을 저장하고 `moving=1`로 둔다.

`loop` 앞부분에서 `moving`이면

```
t = (millis() − moveStartTime) / MOVING_TIME    // 0~1
s = ease(t)                                     // sigmoid 또는 cosine
angle = start + (stop − start) · s
```

로 각도를 쓴다. 직선 `map()` 대신 s가 곡선을 만든다. t≥1이면 목표각을 한 번 더 쓰고 `bar_up`을 갱신한 뒤 `moving=0`.

동작 중에는 새 명령을 받지 않는다. 올리다가 차가 사라져도 끝까지 올린 다음, 다음 주기에서 내린다.

대기 중이면

- 차량이고 바가 내려가 있으면 `start_move(0, 90)`
- 통과했고 바가 올라가 있으면 `start_move(90, 0)`

### loop 구조

서보 갱신은 매 loop, 초음파는 25ms마다. `delay()`로 기다리지 않아서 보간과 측정을 같이 돌릴 수 있다. `pulseIn`의 timeout은 `INTERVAL/2`라서 샘플 주기를 넘기지 않는다.

시리얼에는 `Min, ema, car, bar, Max`를 찍어 감지/바 상태를 확인한다. LED는 차량이면 켜진다(active-LOW).
