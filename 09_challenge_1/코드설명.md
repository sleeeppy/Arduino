# 09C19 도전과제 — 중위수 필터

`09_example_1`을 바탕으로 만들되, **직전 유효값 대체(범위 필터)는 넣지 않았다.** timeout(0) 같은 오류가 버퍼에 그대로 들어가게 해서, 중위수 필터만으로 스파이크가 제거되는지 확인한다.

## 자료구조

최근 N개 샘플을 원형 버퍼 `samples[N_MAX]`에 넣는다. `add_sample()`이 새 값을 덮어쓰고, `sample_count`가 N이 될 때까지 개수를 센다.

N은 배열로 두고 `N_SELECT`만 바꾼다.

```
const int MEDIAN_NS[] = {3, 10, 30};
#define N_SELECT 1   // 1=N3, 2=N10, 3=N30
```

시작 때 LED가 1/2/3번 깜빡여 현재 N을 표시한다.

## 중위수

`median_filter()`는 버퍼를 복사한 뒤 삽입 정렬한다.

- N이 홀수(3, 30): 가운데 값
- N이 짝수(10): 가운데 두 값의 평균

한두 번 timeout이 나와도 정렬 후 양 끝이 되므로 중위수는 정상 거리에 남는다.

## EMA

비교용으로 `EMA = α·raw + (1-α)·이전 EMA` (`α=0.5`)를 같이 출력한다. EMA는 0에도 끌리므로, 같은 화면에서 median이 timeout을 더 잘 막는 것을 볼 수 있다.

## 시리얼 출력 (슬라이드 20쪽)

`Min, raw, ema, median, Max` 순서로 출력한다. N=3 / 10 / 30마다 `N_SELECT`를 바꿔 업로드한 뒤 플로터를 찍는다.

| N | 장점 | 단점 |
|---|---|---|
| 3 | 반응이 빠름 | 연속 오류가 나면 덜 막힘 |
| 10 | 노이즈 제거와 반응의 균형 | 짝수라 두 값 평균 |
| 30 | timeout 제거가 가장 강함 | 움직임이 늦게 반영됨 |
